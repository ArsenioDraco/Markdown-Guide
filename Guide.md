# Markdown Guide/Cheatsheet

A concise reference of common Markdown elements and their output.

---

## Headings
```
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

---

## Emphasis
```
*Italic*  
_Italic_  

**Bold**  
__Bold__  

***Bold Italic***  
___Bold Italic___  
```

---

## Paragraphs and Line Breaks
```
Paragraph text.

New paragraph after a blank line.

Line break uses two spaces at end of line.  
Next line.
```

---

## Lists

### Unordered
```
- Item
- Item
  - Nested item
```

### Ordered
```
1. First
2. Second
3. Third
```

---

## Links
```
[Link text](https://example.com)

[Link with title](https://example.com "Title")
```

---

## Images
```
![Alt text](image-url.png)

![Alt text](image-url.png "Title")
```

---

## Code

### Inline
```
`inline code`
```

### Block
<pre>
```lang
code here
```
</pre>

---

## Blockquotes
```
> Quote
>> Nested quote
```

---

## Horizontal Rule
```
---
***
___
```

---

## Tables
```
| Column 1 | Column 2 |
|----------|----------|
| Cell A   | Cell B   |
| Cell C   | Cell D   |
```

---

## Task Lists
```
- [ ] Incomplete
- [x] Complete
```

---

## Fenced Code Block Highlighting Examples
```
```javascript
console.log("Example");
```

```python
print("Example")
```
```

---

## Escaping Characters
```
\* \_ \# \` \| \\  
Use backslash to escape Markdown symbols.
```

---

## Footnotes (GitHub extended)
```
Text with footnote.[^1]

[^1]: Footnote reference text.
```

---

## Tables of Contents (Generated by GitHub)
GitHub auto-generates TOC on headings for `.md` files navigated in the sidebar; no syntax is required.

---

## HTML Support
```
<b>Bold</b>
<i>Italic</i>
<br>
```

---

## Collapsible Sections (GitHub extended)
```
<details>
  <summary>Click to expand</summary>

  Content.
</details>
```
